---
revisado: true
titulo: Nimbo
resumen: Weather app for anywhere in the world, whose colours change with the weather.
contexto: Personal project to learn SvelteKit and Bootstrap, from sketch to launch.
objetivo: Check the current weather, the next few hours and the next 7 days for any place at a glance, on a phone or a computer.
problema: Many weather sites are full of ads and data and are slow on mobile. Nimbo shows only what matters, loads fast and changes colour so you can tell the weather before reading anything.
usuario: Anyone who wants to check the weather in their city or for a trip without signing up.
estadoTexto: Released in September 2026, with real data from Open-Meteo and 15 automated tests.
funcionalidades:
  - Search for places around the world; when several share a name, the others are offered as alternatives.
  - Weather at the browser's location, if permission is given.
  - Current temperature, feels-like, high and low, and a description of the weather.
  - Next 8 hours with the chance of rain and next 7 days with each day's temperature range.
  - Wind with its direction, humidity, UV index, pressure, sunrise and sunset.
  - 'Five colour themes based on the real weather: sunny, cloudy, rain, night and snow.'
  - Switch between °C and °F, remembered in the browser.
  - Every place has its own link to save or share it.
retos:
  - titulo: Bootstrap with its own identity
    texto: Each weather's colours are CSS variables that replace Bootstrap's own, so the grid and components change theme without rewriting their styles.
  - titulo: The place's time, not the server's
    texto: Open-Meteo returns local time without a time zone; it is read as is so the date and hours are those of the place, not the server's or the browser's.
  - titulo: Fast, with JavaScript optional
    texto: The page is server-rendered, the search is a plain form and Vercel's CDN caches each place for 10 minutes, the same time Open-Meteo takes to update its data.
  - titulo: Built for mobile
    texto: It was tested on an emulated phone, and a horizontal overflow caused by screen-reader-only text inside the hours row was fixed.
mejoras:
  - Show the city name when using the browser's location (it currently says "Tu ubicación").
  - Save favourite places.
  - Add severe weather warnings.
arquitectura:
  nodos:
    - titulo: Browser
      detalle: Svelte 5 · Bootstrap 5.3 · weather themes
    - titulo: SvelteKit on Vercel
      detalle: server rendering and a 10-minute CDN cache
      destacado: true
    - titulo: Open-Meteo
      detalle: forecast and place search · no API key
  nota: When changing places, the browser requests the data straight from Open-Meteo.
